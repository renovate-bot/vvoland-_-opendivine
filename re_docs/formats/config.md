# `config.div` / `config.lcl` / `keylist.txt` — config & keybindings

The game's plain-text configuration. All three are line-based ASCII.

## `config.div` / `config.lcl` — engine settings

One **`<command> <value>`** per line; `//` starts a comment (in
`config.div`). The commands are a subset of the internal script
vocabulary ([`../script-commands.md`](../script-commands.md)) applied at
startup. `config.div` holds display defaults; `config.lcl` is the
**local** (per-machine) override with more runtime knobs:

```text
config.div:                  config.lcl:
  width 1024                   width 800
  height 768                   height 600
  smooth 1                     game rate 40 fps
  no fog                       music 1
                               memory limit 32
                               language 1
                               images compressed
                               flat files
                               debug on
```

Notable: **`game rate 40 fps`** sets the engine tick rate. Combined
with the world clock's `TicksPerHour = 2880`
([`../world-clock.md`](../world-clock.md)), and assuming the clock
advances once per tick, a game **hour ≈ 2880 / 40 = 72 real seconds**,
so a full game day ≈ 28.8 minutes of real time. `images compressed` /
`flat files` select asset packing; `language 1` picks the localization
([`../dialogue.md`](../dialogue.md)); `no fog` disables the shroud
([shroud.md](shroud.md)).

## `keylist.txt` — keybindings

Tab-separated, with a self-describing header. Each binding:

```text
UniqueID   Flags          Keyname / Character
  <0 = an Event, >0 = a floating icon (hotbar slot)
  Flags  = combination of SHIFT / ALT / CTRL
  Keyname for VK_* keys, or a single Character code (char wins over key)
```

Examples (`-` = unset):

```text
-2   ctrl f12   -        # event id 2, Ctrl+F12
-8   -   -   l           # event id 8, key 'l'
-14  - space  -          # event id 14, Space
```

Negative ids are **events** (the input actions in `divinityevent.dat`,
below); positive ids are floating hotbar icons. The file is
auto-generated by the engine.

## `divinityevent.dat` — the keybindable action registry

A 388-byte plain-text file: 20 **`"quoted"` action names**, one per line
(`\r\n`-terminated). These are the named input/UI events that
`keylist.txt`'s negative ids bind to — the `keylist.txt` event id is the
**1-based line index** into this list (e.g. id 8 = the 8th entry, "Open
Load Plate"). Full list, in order:

```text
 1 Drop Console            8 Open Load Plate        15 NextHour
 2 Toggle KeyPlate         9 Open Save Plate         16 AutoMap
 3 Icon Hotkey Assign     10 Open Status Plate       17 ClearShroud
 4 Toggle OptionsPlate    11 Open Inventory          18 ScaleAutoMapUp
 5 Toggle NonEnergy Plate Visibility  12 StartEditor 19 ScaleAutoMapDown
 6 Toggle Plate Visibility 13 SwitchEditor           20 SwitchCombatMode
 7 Toggle Show Icon Hotkey 14 PauseGame
```

Notable: `StartEditor`/`SwitchEditor` (the bundled level editor),
`NextHour`/`ClearShroud`/`Drop Console` (dev/debug actions), plus the
normal UI toggles, automap zoom, and `SwitchCombatMode`.

## Status

  comments); a startup subset of the script-command vocabulary.
- `game rate 40 fps` ✅ — fixes the day/night wall-clock rate (~72 s per

- `keylist.txt` ✅ — `UniqueID, Flags, Keyname/Char` per the file's own
  header; negative ids = events (1-based index into `divinityevent.dat`),
